# GVC Escuela — Sitio Web Institucional

Sitio de presentación para institución educativa real en Arequipa, Perú.  
Diseño responsivo con secciones de servicios, galería y formulario de contacto.

**Demo en vivo:** [gvc-eventos.netlify.app](https://gvc-eventos.netlify.app/)

---

## Stack

- HTML5
- CSS3 (responsivo, Flexbox)
- JavaScript vanilla

## Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Estructura principal de la página |
| `styles.css` | Estilos y diseño responsivo |
| `script.js` | Interactividad (menú móvil, animaciones) |
| `logo-gvc.jpeg` | Logo del cliente |

---

## Secciones

- **Hero** con llamada a la acción
- **Servicios** ofrecidos por la institución
- **Galería** de instalaciones
- **Contacto** con formulario
